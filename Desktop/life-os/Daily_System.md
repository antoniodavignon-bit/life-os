# ⚡ Daily Execution System

> **The rule is simple: 9 tasks per day across 3 categories. No exceptions.**

---

## Daily Structure

### 🟢 Block 1 — Revenue Tasks (3 per day)
Direct money-generating actions. These happen FIRST.

| Slot | Task | Done? |
|------|------|-------|
| R1 | | ☐ |
| R2 | | ☐ |
| R3 | | ☐ |

**Examples:**
- Post a product offer on social media
- Follow up with 3 leads
- List a new product or service
- Run an ad or send a sales email

---

---

| Slot | Task | Done? |
|------|------|-------|
| M1 | | ☐ |
| M2 | | ☐ |
| M3 | | ☐ |

**Examples:**
- Exercise or movement

---

## 🌙 Night Review (End of Every Day)

Answer these 4 questions before you sleep:

1. **What produced income today?**  
   → Repeat this tomorrow.

2. **What failed or wasted time?**  
   → Cut it or fix it.

3. **What carries over to tomorrow?**  
   → Move it forward, not backward.

4. **What is the #1 priority tomorrow morning?**  
   → Write it down now.

## The Rule

> If the 9 tasks are done, the day was productive — regardless of how you feel.

Feelings are not metrics. Execution is.
