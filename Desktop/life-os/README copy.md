# 🧠 Life OS — Personal Operating System

> **Stop living without structure. Start executing with a system.**

Life OS is a structured operating system for goals, execution, and business growth. It converts scattered effort into predictable output across Income, Health, Skills, and Daily Discipline.

---

## 📦 What's Inside

| File | Purpose |
|------|---------|
| `Vision.md` | Core mission and outcome targets |
| `Product_PRD.md` | Product requirements & module breakdown |
| `Roadmap_90_day.md` | 90-day build and launch plan |
| `Daily_System.md` | Daily execution framework |
| `Sales_Page_Copy.md` | Landing page & sales copy |
| `Ads_Scripts.md` | Ad hooks, scripts, and CTAs |
| `User_Personas.md` | Target user profiles |
| `System_Architecture.md` | Technical module map |
| `Automation_Scripts/` | Python scripts for task generation & profit tracking |

---

## 🚀 Quick Start

### 1. Clone the Repo
```bash
git clone https://github.com/YOUR_USERNAME/life-os.git
cd life-os
```

### 2. Run the Daily Task Generator
```bash
python Automation_Scripts/daily_task_generator.py
```

### 3. Track Your Profit
```bash
python Automation_Scripts/profit_tracker.py
```
